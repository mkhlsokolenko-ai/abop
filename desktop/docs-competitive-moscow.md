# APE Desktop — конкурентный разбор, MoSCoW и гэпы бэкенда

Анализ дизайна десктопных Claude Code / ChatGPT / Qwen / DeepSeek → перечень топ-фич →
приоритизация MoSCoW (с учётом всех запросов лектора) → сверка с нашим беком и гэпы.

## 1. Что делают конкуренты (топ-паттерны дизайна)

| Продукт | Сильные стороны дизайна / ключевые фичи |
|---|---|
| **Claude Code** | агентный loop с инструментами, **approval-гейты** на действия, plan mode, **thinking/прогресс виден**, sub-agents, MCP-инструменты, **скиллы**, память (CLAUDE.md), фоновые задачи, чекпоинты/undo, @-файлы, todo-трекинг. Транспарентность: видно каждый tool-call. |
| **ChatGPT** | треды + поиск по истории, **Projects** (папки: чаты+файлы+инструкции), загрузка файлов/картинок, **Canvas** (боковой редактор доков/кода), voice, web search, memory + custom instructions, **companion-окно + глобальный хоткей**, «work with apps» (читает контекст открытых приложений), экспорт. |
| **Qwen Chat** | пикер моделей (вкл. reasoning), файлы/картинки, web search, **артефакты**, deep research, конструктор агентов/приложений, мультимодальность. |
| **DeepSeek** | минимализм, **2 тумблера: DeepThink (reasoning) и Search**, файлы, история. Быстро, ничего лишнего. |

**Общий знаменатель у всех:** стриминг ответа, действия над сообщением (stop/copy/regenerate/edit), markdown+код с копированием, управление тредами (поиск/переименование/пин), вложения с Q&A, память/персона, тумблеры режимов, аккаунт/лимиты.

## 3. MoSCoW для APE Desktop
(⭐ — запрошено лектором; ✅ — уже сделано в этой сессии; 🔧 — нужен бэкенд)

### MUST — базовый паритет чата + сообщённые баги
- **Стриминг ответа** ⭐🔧 — построчно, виден прогресс. *(гэп: серверный SSE через шлюз)*
- **Маршрутизация в наш self-host 30B** ⭐✅ — убран облачный primary (все профили → `local/qwen3-30b-a3b`).
- **Агенты с выбором ролей + цепочка** ⭐✅ — модалка (native `prompt()` в Electron не работает!), роли из пресетов, выполняются цепочкой.
- **Видимые проиндексированные файлы** ⭐✅ — «база знаний чата» со списком/удалением.
- **Личный кабинет: токены/остаток/₽** ⭐✅ — модуль `cabinet` (my_usage).
- **Действия над сообщением** 🔧частично — stop-генерации (нужен стриминг), copy, regenerate.
- **Рендер markdown/кода + копирование** — сейчас plain-text; нужен markdown-рендер.
- **Rename + авто-тема + избранное тредов** ⭐✅.
- **Скиллы из UI** ✅ (галочки, подмешиваются в system).

### SHOULD — рабочая мощь
- **Кнопки инструментов OCR / NLP / RAG** ⭐ — RAG ✅; **OCR** (модуль `ocr-tesseract`) 🔧; **NLP** (извлечение сущностей/классификация) 🔧.
- **Конструктор агента** ⭐🔧 — задать скилл/шаги/DoD/анти-паттерны, сохранить, **объединять в цепочку** при постановке задачи. *(сейчас роли — фикс-пресеты; нужен редактор + хранилище + подгрузка полной методики скилла)*
- **Reasoning-тумблер / пикер режима** — маппинг на профиль (`ask`=DeepSeek reasoning).
- **Web search** 🔧 — инструмент поиска через шлюз.
- **Память + custom instructions (персона)** — на пользователя/тред.
- **Projects/папки** тредов; **edit сообщения + ветвление**.
- **Глобальный хоткей / быстрый лаунчер** (Electron globalShortcut + tray).
- **Экспорт чата** (md).

### COULD — продвинутое/энтерпрайз
- **Рабочие источники (Word/Excel/ИС, последние файлы → контекст в чате)** ⭐🔧 — коннекторы поверх **ABOP Data Plane** (в ape уже есть `/data`: source→canonical JSON, адаптеры csv/json/http/sqlite — расширить на docx/xlsx + «recent files»).
- **RBAC (роли/доступ к инструментам и источникам)** ⭐🔧 — поверх Keycloak-ролей + политика в шлюзе. ABOP.
- **Артефакты/Canvas** (боковой редактор), **voice**, **vision/генерация картинок**, **темы**.

### WON'T (сейчас)
- Полная мультимодальная генерация (video/image), маркетплейс плагинов, риалтайм-коллаборация.

## 4. Сверка с беком и гэпы

| Фича | Статус бэка | Что доработать | Оценка |
|---|---|---|---|
| Стриминг | ❌ MCP `chat` блокирующий | SSE в `server/clients.py` (stream) + стрим-эндпоинт (MCP-tool или portal_api SSE) → сайдкар проксирует в UI. Квоту/cost логировать по финальному usage-чанку | High |
| Маршрутизация→self-host | ✅ | сделано (`.env` cascades: code/research/standard → `local/`) | — |
| Агенты (роли+цепочка) | 🟡 клиентская цепочка в сайдкаре | для ape-стиля (волны/Blackboard/tool-calling) — портировать движок агентов ape в сайдкар или в MCP | Med |
| Конструктор агента (скилл/шаги/DoD/анти) | ❌ | хранилище агентов/скиллов (per-user) + редактор + подгрузка полной методики `SKILL.md` в system (сейчас только краткие hints). Это **ABOP Tool plane** | Med-High |
| Видимые файлы | ✅ локально | опц. листинг S3 через `portal_api/storage` (уже есть) | Low |
| Кабинет/расход | ✅ `my_usage` | графики истории — `portal_api /api/my/cost-daily` (есть) | Low |
| OCR | ❌ | модуль `ocr-tesseract`: pytesseract + бинарь Tesseract в extraResources; панель скан→текст→RAG | Med |
| NLP мини-нейронки | ❌ | модули на onnxruntime/sklearn (классификация писем/заявок, извлечение сущностей), локально | Med |
| Web search | ❓ | инструмент поиска через шлюз (у deep-research-скилла есть веб-доступ — вынести в tool) | Med |
| Рабочие источники (Office/ИС) | 🟡 есть база: ape `/data` | адаптеры docx/xlsx + «recent files» → canonical context; выбор источника в чате. **ABOP Data Plane** | High |
| RBAC | 🟡 Keycloak роли student/lecturer | политика доступа к инструментам/источникам в шлюзе + UI настройки. **ABOP** | Med-High |
| Действия/markdown/копир. | ❌ (frontend) | markdown-рендер (marked) + copy-code + regenerate/stop | Low-Med |
| Reasoning-тумблер | ✅ профили | UI-тумблер → profile `ask` | Low |
| Глобальный хоткей | ❌ | Electron `globalShortcut` + tray-иконка | Low-Med |

## 5. Рекомендованный порядок
1. **Стриминг** (Must, самый заметный UX; серверная работа) — топ-приоритет.
2. **Markdown/код-рендер + действия над сообщением** (Must, чисто фронт, дёшево).
3. **Конструктор агента + цепочки** (Should, ⭐) — заодно фундамент ABOP Tool plane.
4. **OCR-модуль**, затем **NLP-модули** (Should, ⭐).
5. **Рабочие источники (Office/recent) + RBAC** (Could, ⭐) — на смычке с ABOP.
