# APE Desktop — дизайн-хендофф (для отрисовки макета)

Бриф для дизайнера: визуальный язык (из бренд-кита ABOP с Эйпом), каркас, компоненты, все
экраны и **все запланированные фичи** с лучшими UI/UX-паттернами конкурентов. Цель — макет
устанавливаемого тонкого клиента-агента (см. стратегию `docs-thin-client-adr.md`).

## 0. Источники
- **Бренд-кит (цвета/кнопки/маскот Эйп):** `Desktop/abop/docs/Бренд-кит ABOP с Эйпом7.zip` →
  `ABOP Brand Kit.dc.html`, `Ape.dc.html`, `Overlays.dc.html`, прототипы `ABOP v3 (standalone).html`.
- Фичи и логика: `docs-thin-client-adr.md`, `docs-ux-usability.md`, `docs-competitive-moscow.md`, `README.md`.

## 1. Визуальный язык (из бренд-кита ABOP)
- **Стиль:** **glassmorphism** — полупрозрачные панели, `backdrop-filter: blur(16px)`, тонкие светлые границы (1px, белый 8–12%), мягкие тени, радиальные **градиенты-свечения** под индиго на фоне.
- **Палитра (hex из бренд-кита):**
  - Primary indigo: `#6366f1` (осн.), `#4f46e5` / `#4338ca` (нажатие/тёмный), light `#818cf8` / `#a5b4fc`.
  - Violet: `#8b5cf6` / `#7c3aed` (вторичный акцент, градиенты).
  - Success emerald `#34d399` · Warning amber `#fbbf24`/`#f59e0b` · Danger `#991b1b`/red.
  - Тёмная база: `#0f172a` (slate-950), `#1e1b4b` (indigo-950) — фон под стеклом.
- **Шрифт:** **Inter** (400/500/600/700); моно для кода/токенов — по вкусу (JetBrains Mono/ui-monospace).
- **Скругления:** карточки/панели 12–16px; кнопки/чипы — pill (`9999px`).
- **Маскот Эйп:** приветствие/пустые состояния/ожидание («язык ожидания»), спиннеры, онбординг, тосты. Ненавязчиво, не в рабочих зонах.
- **Темы:** тёмная (осн., стекло на indigo-glow) и **светлая** (стекло на светлом фоне) — обе обязательны, переключатель в шапке.

## 2. Каркас экрана (3 зоны + правая шторка)
```
┌───┬───────────────────────────────────────────┬─────────────┐
│ L │  Верхняя панель: лого·Эйп · версия · тема · │  ПРАВАЯ     │
│ р │  расход сессии · баннер апдейта             │  ШТОРКА     │
│ е ├───────────────────────────────────────────┤  (выезжает) │
│ й │  Треды | Диалог (стекло-пузыри) | Композер  │  Инструменты│
│ л │                                             │  /Агенты    │
└───┴───────────────────────────────────────────┴─────────────┘
```
- **Левый рейл (настраиваемый):** модули (Чат, Кабинет, …) + **зона быстрых функций** — пользователь **назначает** сюда часто используемые агенты/инструменты/шаблоны (drag-drop, «закрепить»). Пустые слоты с «+». Иконки стеклянные, активный — indigo-подсветка.
- **Правая шторка (drawer):** **выезжает справа** для вызова инструментов — OCR / NLP / RAG-вложения / **каталог агентов** / экспорт. Стеклянная панель поверх диалога, затемняет фон, закрывается по клику-вне/Esc. Ширина ~360–420px. Внутри — список инструментов с описанием и кнопкой запуска; для агентов — карточки + «Настроить/Собрать цепочку».
- **Центр:** сайдбар тредов (поиск, избранное, папки) + поток сообщений (пузыри-стекло) + композер.

## 3. Компоненты (нарисовать в двух темах)
- **Кнопки:** primary (indigo-заливка, pill), secondary (стекло, 1px граница), ghost (текст+иконка), danger. Состояния: hover/active/disabled/loading (Эйп-спиннер).
- **Пузыри сообщений:** пользователь — indigo-tint стекло справа; ассистент — нейтральное стекло слева; под ответом действия (⧉ копировать · ↻ ещё раз · ✎ изменить у своих). Блоки кода — тёмное стекло + кнопка «копир.».
- **Чипы:** скиллы (вкл/выкл, pill), профиль/режим, статусы (индексирую/ищу/агент работает).
- **Поля/селекты:** стеклянные, indigo-focus ring.
- **Модалки/поповеры:** стекло, blur фон. **Командная палитра** (Ctrl+K) — центральный стеклянный поповер со списком действий.
- **Баннеры:** апдейт (indigo, кнопка «Перезапустить и обновить»), ошибка (danger + «Повторить»), офлайн/квота.
- **Тосты:** короткие, с Эйпом.

## 4. Экраны и панели (что отрисовать)
1. **Главный — Чат.** Тред-сайдбар (поиск, «+ Новый», избранное ★, папки), поток, композер (профиль/режим, чипы скиллов, 📎, 🕸 Агенты, 📥 Экспорт, поле + Отправить/⏹ Стоп). Стриминг: текст набегает, «▍ думает…» до первого токена, cost/токены под ответом.
2. **Правая шторка — Инструменты/Агенты.** Вкладки: Инструменты (OCR/NLP/RAG/Экспорт) и **Каталог агентов** (карточки, фильтр по роли RBAC). Кнопка на каждом — «Запустить»; на агенте — «Настроить».
3. **Конструктор агента.** Форма: имя, скилл(ы), шаги, DoD, анти-паттерны; **цепочка** ролей (визуальные блоки «Ресёрчер → Аналитик → Критик», перетаскивание/добавление). Предпросмотр.
4. **Кабинет.** Расход (токены/₽/остаток, графики), **RBAC** (роли/доступ — что можно), **Рабочие источники** (Office/ИС/последние файлы — подключить, статус), настройки (тема, дефолты, персона/инструкции, шорткаты).
5. **Пустой экран (онбординг).** Эйп + шаблоны-карточки под менеджера (письмо/саммари/отзывы/идея/сравнение/план). Первый запуск: 3 шага (вход → шаблон → файл).
6. **Командная палитра (Ctrl+K)** и **глобальный оверлей-лаунчер** (Ctrl+Space поверх любых приложений): поле + быстрые агенты/действия, работа с выделенным текстом.
7. **Office-надстройка (task-pane).** Узкая версия чата/каталога внутри Word/Excel: контекст текущего документа как источник, кнопка на ленте.
8. **Состояния апдейтера** (скачивается %/готово+кнопка) в шапке.

## 5. Все запланированные фичи (чеклист для макетов)
**Чат/сообщения:** стриминг · markdown+код с копированием · действия (копировать/изменить/ещё раз/стоп) · индикатор «думает» · ошибки с «Повторить».
**Треды:** новый/переименование/**авто-тема**/избранное/удаление · **поиск** · **папки/проекты**.
**Знания/файлы:** вложения → база знаний чата (список, удаление) · **drag-drop** · цитаты источников.
**Инструменты (правая шторка):** RAG · **OCR** · **NLP** · экспорт **md/pdf/docx/xlsx** в «Загрузки».
**Агенты:** каталог (по RBAC) · **конструктор** (скилл/шаги/DoD/анти) · **цепочки** · пошаговый вид выполнения.
**Настройка:** темы (свет/тьма) · **горячие клавиши** · **командная палитра** · персона/custom instructions · дефолты · **настраиваемое левое меню** быстрых функций.
**Идентичность/доступ:** вход GitHub · **RBAC** (видимость по роли) · рабочие источники под правами пользователя.
**Поверхности вызова:** окно · **глобальный хоткей/оверлей** · **Office-надстройка** · deep-link.
**Система:** видимый **авто-апдейтер** · расход/квота · офлайн/ошибки.

## 6. Лучшие UX-паттерны конкурентов (заимствуем — по экранам)
- **ChatGPT/Claude:** пустой экран с примерами; поиск по чатам; проекты/папки; **командная палитра**; **глобальный хоткей/companion-окно**; edit-and-resubmit; стриминг + стоп; кабинет/лимиты. → экраны 1,5,6.
- **Claude Code:** прозрачность действий (видно, что делает инструмент/агент по шагам); approve/deny на действия; keyboard-first. → правая шторка (шаги агента), экран 2/3.
- **Perplexity:** цитаты-источники под ответом; follow-up-подсказки. → экран 1 (цитаты, чипы «уточнить/короче/в таблицу»).
- **DeepSeek/Qwen:** минимализм; тумблер «думать глубже» (reasoning); тумблер web-поиска. → композер (режим/тумблеры).
- **Cursor:** пошаговый review результата (accept/reject). → результат агента/экспорт.

## 7. Состояния (нарисовать для ключевых экранов)
empty · loading/стриминг («думает» → набегающий текст) · error+retry · drop-target (подсветка «отпусти файл») · **RBAC-gated** (недоступный агент/источник — замок + подсказка) · offline/квота исчерпана · апдейт готов.
