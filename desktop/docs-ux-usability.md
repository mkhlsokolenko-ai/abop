# APE Desktop — UX/UI-анализ и юзер-френдли фичи

Разбор UX-паттернов десктопных ИИ-клиентов (Claude Desktop/Code, ChatGPT, Qwen, DeepSeek,
+ Cursor, Perplexity как референсы) по 4 осям: **управляемость · настраиваемость ·
простота/онбординг · скорость/доверие**. Для каждой — что делают конкуренты, что есть у нас
(v0.1.2), и перечень юзер-френдли фич с приоритетом (MoSCoW). Продуктовые фичи уже есть —
здесь про **удобство для пользователя-менеджера**. Питает будущий заход по дизайну/полировке.

Легенда: ✅ есть · 🟡 частично · ❌ нет · (F) чисто фронт (дёшево, без риска сборки) · (B) нужен бэкенд.

---

## Ось 1. Управляемость (контроль над агентом)

**Конкуренты:** Claude — plan mode, **approve/deny на действия tool**, прерывание (Esc),
**edit-and-resubmit**, checkpoints/rewind, видимость «размышления» и tool-calls по шагам.
ChatGPT — stop, **edit сообщения**, regenerate (+ выбор модели), ветвление. DeepSeek/Qwen —
тумблер reasoning (видно, как думает). Cursor — **пошаговый review диффов** accept/reject.

**У нас (v0.1.2):** ✅ стоп-генерация · ✅ regenerate (↻) · ✅ копировать · ✅ выбор профиля ·
🟡 агенты выполняются цепочкой, но **итог склеен** (нет пошаговой видимости) · ❌ edit сообщения ·
❌ ветвление · ❌ approve/deny действий · ❌ откат.

**Юзер-френдли фичи:**
- **Edit & resend** пользовательского сообщения (F) — правишь вопрос, ветка перезапускается. *Must*
- **Пошаговый вид агентов** (F) — свернутые карточки ролей «Ресёрчер → Аналитик → Критик» со статусом, а не одна простыня. *Should*
- **Approve/deny на внешние действия** (B) — когда агент пишет/отправляет/коммитит: предпросмотр + подтверждение. *Could* (ABOP governance)
- **Ветвление/версии ответа** (F) — переключение между regenerate-вариантами. *Could*

## Ось 2. Настраиваемость

**Конкуренты:** ChatGPT — **custom instructions + постоянная память**, Projects с
пер-проектными инструкциями, voice, model picker. Claude — **CLAUDE.md** (инструкции проекта),
slash-команды, MCP-серверы, output styles, keyboard-first. Qwen — пикер моделей/режимов,
web-search тумблер. Тема (свет/тёмная) — почти у всех.

**У нас:** ✅ скиллы галочками · ✅ профиль на тред · 🟡 память треда (дистилляция) без
пользовательской персоны · ❌ custom instructions/персона · ❌ светлая тема · ❌ шорткаты ·
❌ пер-пользовательские дефолты (профиль/скиллы по умолчанию).

**Юзер-френдли фичи:**
- **Custom instructions / персона** (B, мелкий) — «кто я, как отвечать»: глобально + на тред, подмешивается в system. *Should*
- **Светлая тема + переключатель** (F) — токены темы уже вынесены в `theme.css`, добавить второй набор + тумблер. *Must* (дёшево, заметно)
- **Горячие клавиши** (F) — Ctrl+Enter отправить, Esc стоп, Ctrl+K палитра, Ctrl+N новый чат. *Must*
- **Дефолты пользователя** (F/B) — профиль/скиллы по умолчанию для новых чатов. *Should*
- **Настройки в Кабинете** (F) — единая вкладка: тема, дефолты, персона, шорткаты. *Should*

## Ось 3. Простота / онбординг

**Конкуренты:** ChatGPT — **пустое состояние с примерами промптов**, drag-drop файлов, поиск по
чатам, папки/Projects. Claude — `/help`, discoverability slash-команд, минимум хрома. Perplexity —
follow-up-подсказки. Общее: **шаблоны/пресеты задач**, чистый первый экран.

**У нас:** ✅ пустое состояние (текст-подсказка) · ✅ треды/избранное/авто-тема · 🟡 скиллы видны,
но без пояснения «зачем» на старте · ❌ **поиск по чатам** · ❌ шаблоны/примеры промптов ·
❌ drag-drop файлов · ❌ папки/группы · ❌ онбординг первого запуска.

**Юзер-френдли фичи:**
- **Поиск по чатам** в сайдбаре (F) — фильтр по названию/содержимому. *Must*
- **Пустой экран с шаблонами** под менеджера (F) — 4–6 карточек: «разобрать отзывы», «письмо клиенту», «саммари встречи», «проверить идею» → вставляют готовый промпт (+ нужный скилл). *Must*
- **Drag-drop файлов** в окно чата (F) — вместо только кнопки. *Must*
- **Онбординг первого запуска** (F) — 3 шага: вход → выбери шаблон → приложи файл. *Should*
- **Папки/проекты** для чатов (B, мелкий) — группировка. *Should*
- **Подсказки-follow-up** после ответа (B) — «уточнить», «короче», «в таблицу». *Could*

## Ось 4. Скорость / доверие

**Конкуренты:** streaming везде; **статус инструментов** («ищу в вебе…», «читаю файл…») с
**источниками/цитатами** (Perplexity, ChatGPT search); **copy на блоках кода**; видимость
контекста/токенов; понятные ошибки с retry; DeepSeek — видимая цепочка рассуждений.

**У нас:** ✅ streaming · ✅ cost/токены на сообщении · ✅ markdown · ✅ видимый апдейтер ·
🟡 ошибки текстом в пузыре (без retry-кнопки) · ❌ **copy на блоках кода** · ❌ статус
инструментов (RAG/агенты идут молча) · ❌ цитаты источников из RAG · ❌ бегущий счётчик
сессии в шапке · ❌ индикатор «печатает…» до первого токена.

**Юзер-френдли фичи:**
- **Copy-кнопка на блоках кода** (F). *Must*
- **Статусы инструментов** (F/B) — «📎 индексирую…», «🔎 ищу по документам…», «🕸 Аналитик работает…». *Must*
- **Цитаты источников** из вложений (B) — какой документ дал ответ (RAG уже знает чанки). *Should*
- **Счётчик сессии в шапке** (F) — токены/₽ этой сессии + остаток недельной квоты. *Should*
- **Ошибки с retry** (F) — кнопка «повторить» вместо текста ошибки. *Must*
- **Индикатор «думает…»** до первого токена (F). *Must*

## Сводный MoSCoW (юзер-френдли UX)

**MUST (все чисто фронт, дёшево, до дизайн-полировки):**
поиск по чатам · пустой экран с шаблонами под менеджера · drag-drop файлов · edit&resend ·
светлая тема + тумблер · горячие клавиши · copy на блоках кода · статусы инструментов ·
ошибки с retry · индикатор «думает…».

**SHOULD:** custom instructions/персона · командная палитра (Ctrl+K) · настройки в Кабинете ·
дефолты пользователя · пошаговый вид агентов · папки/проекты · цитаты источников · счётчик сессии ·
онбординг первого запуска · глобальный хоткей/квик-лаунчер.

**COULD:** approve/deny действий (ABOP) · ветвление ответов · follow-up-подсказки · web search + панель источников · voice · canvas/артефакты.

**WON'T (сейчас):** мультиокна/коллаборация, маркетплейс, генерация картинок.

## Рекомендованный первый заход (MUST — 1–2 релиза, всё фронт)
1. **Пустой экран с шаблонами + поиск по чатам** — сразу поднимает «понятность» для менеджера.
2. **Светлая тема + горячие клавиши + drag-drop** — базовый комфорт.
3. **Copy на коде + индикатор «думает…» + статусы инструментов + ошибки с retry** — доверие/скорость.
4. **Edit & resend** — управляемость.

Всё это — `ui/` (тема в `theme.css`, логика в модулях), без риска для PyInstaller-бандла;
ложится ровно перед заходом по общему дизайну/полировке. Продуктовые фичи (Word/Excel-экспорт,
конструктор агента, OCR/NLP, рабочие источники) — параллельная продуктовая ветка (см.
`docs-competitive-moscow.md`).
