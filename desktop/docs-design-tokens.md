# APE Desktop — дизайн-токены и раскладка (снято с макета)

Извлечено из макета **`APE Desktop.dc.html`** (Бренд-кит ABOP с Эйпом9) — готово под перенос в
`ui/core/theme.css` и перекомпоновку. Стиль: **glassmorphism на indigo-mesh фоне**, шрифт Inter.

## 1. Токены (тёмная тема — как в макете)
```css
:root{
  --bg:        #0f172a;                    /* slate-950, база под стеклом */
  --mesh-a:    rgba(99,102,241,.16);       /* indigo glow (радиальный) */
  --mesh-b:    rgba(139,92,246,.14);       /* violet glow */
  --panel:     rgba(255,255,255,.05);      /* стекло-панель */
  --panel-2:   rgba(255,255,255,.08);      /* стекло-панель ярче */
  --hover:     rgba(255,255,255,.09);
  --line:      rgba(255,255,255,.10);      /* границы 1px */
  --line-2:    rgba(255,255,255,.16);
  --field:     rgba(15,23,42,.55);         /* инпуты */
  --rail:      rgba(15,23,42,.60);         /* левый рейл */
  --code:      #0b1020;                     /* блоки кода */
  --ink:       #ffffff;                     /* текст */
  --ink-2:     rgba(255,255,255,.62);
  --ink-3:     rgba(255,255,255,.42);
  --accent:    #6366f1;                     /* indigo primary (заливка) */
  --accent-2:  #818cf8;                     /* indigo светлее */
  --accent-ink:#c7d2fe;                     /* акцент-текст на стекле */
  --accent-ink-2:#a5b4fc;
  --violet:    #8b5cf6;                     /* вторичный акцент/градиенты */
  --deep:      #3730a3;                     /* тёмный индиго (нажатие) */
  --warn-ink:  #fbbf24;  --ok-ink: #6ee7b7;  --danger-ink: #fca5a5;
}
```
- **Стекло:** `backdrop-filter: blur(16px)` панели, `blur(20px)` шторка/оверлеи, `blur(6px)/blur(2px)` слои.
- **Фон:** `--bg` + два радиальных mesh-градиента (`--mesh-a` сверху-слева, `--mesh-b`) — «свечение».
- **Шрифты:** `Inter` (UI), `JetBrains Mono` (код/токены).
- **Скругления:** pill `9999px` (кнопки/чипы), карточки/панели `10–12px`, мелочь `6–8px`.
- **Тени:** шторка `-20px 0 50px rgba(0,0,0,.32)`, модалка `0 24px 70px rgba(0,0,0,.45)`, карточка `0 16px 40px rgba(0,0,0,.4)`.
- **Светлая тема:** инвертировать base (`--bg` светлый, `--panel` тёмное стекло на светлом) — второй набор переменных.

## 2. Раскладка (зоны из макета)
```
┌ topbar ─────────────────────────────────────────────────────────────┐
│ Эйп·лого · [ Поиск и команды  Ctrl+K ] · тема · ⌁ · баннер апдейта    │
├ rail(~240px) ┬ центр (чат) ───────────────────────┬ ШТОРКА (blur20) ─┤
│ ＋ Новый тред │ пусто: «С чего начнём?» + шаблоны   │ Инструменты/     │
│ треды: title/ │ сообщения (⧉ копировать · ↻)        │ Каталог агентов/ │
│ meta · ★ · ✕  │ композер: 📎 🕸 📥 ⏹ ↑              │ Роли · Источники │
│ ─ быстрые фн  │                                    │ Разрешить/Откл.  │
│ {{fu.label}}  │                                    │ (approve-гейты)  │
└──────────────┴────────────────────────────────────┴──────────────────┘
```
- **Топбар:** маскот/лого · **командная палитра** (Поиск и команды, Ctrl+K) · тема · апдейт-баннер («Перезапустить и обновить») · «Повторить подключение» (офлайн).
- **Левый рейл (~240px, `--rail`):** «＋ Новый тред», список тредов (`title/meta/★/✕`), ниже **быстрые функции** (`{{fu.label}}` — настраиваемые).
- **Центр:** пустой экран «С чего начнём?» + карточки-шаблоны (grid `minmax(214px)`), поток сообщений (действия ⧉/↻), композер с иконками 📎 вложение · 🕸 агенты(шторка) · 📥 экспорт · ⏹ стоп · ↑ отправить.
- **Правая шторка (blur20, тень -20px):** Инструменты · **Каталог агентов** (карточки `minmax(190px)`) · Роли · **Рабочие источники** · **approve/deny** («Разрешить/Отклонить», «Принять/Отклонить»).
- **Отдельные экраны:** **Кабинет**, **Конструктор агента** (шаги с `↑ ↓ ✕ ＋шаг`, «Предпросмотр», «Сохранить агента»).

## 3. Что макет добавляет к текущей сборке (новое)
- **Командная палитра** Ctrl+K (в топбаре, заметная) — у нас была Should, тут центральная.
- **Approve/deny гейты** («Разрешить/Отклонить», «Принять/Отклонить») — подтверждение действий агента (governance) — визуально заложено.
- **Быстрые функции в рейле** (`{{fu.label}}`) — настраиваемые, как в хендоффе.
- **Рабочие источники** в шторке/кабинете.
- Полное **стекло** + indigo-mesh фон + Эйп.

## 5. План полировки (по этому макету)
1. **theme.css → стеклянный ABOP** (токены выше, тёмная+светлая, mesh-фон, Inter, тени). Базовые компоненты (кнопки pill/glass, панели, чипы, пузыри) на новые переменные.
2. **Топбар:** командная палитра Ctrl+K (у нас была в roadmap) + баннер апдейта (есть) + тема (есть).
3. **Рейл:** стекло + зона быстрых функций (настраиваемые).
4. **Шторка:** перевести на blur20/тень, вкладки Инструменты/Каталог/Роли/Источники (каталог уже интегрирован).
5. **Конструктор агента:** привести к макету (шаги ↑↓✕＋, предпросмотр) — логика уже есть.
6. **Approve/deny** — заложить в запуск действий агента (governance, позже с RBAC).
> Логика/фичи уже построены (v0.1.2–0.1.6) — полировка = визуальный слой + командная палитра + approve-гейты. Риска для сборки нет (фронт).
