# Пример для лекции: агент владельца кофейни

Канонический пример из программы курса (источник идей, §Kaggle):

> Датасет отзывов → **агент для владельца кофейни, который читает все отзывы за
> неделю и предлагает 3 действия на понедельник.**

Он показывает на одной лекции **весь стек курса сразу**, без единого прямого вызова
LLM-провайдера — всё через курсовой MCP:

1. **Аутентификация** — клиент ходит в MCP с JWT (в проде — от Keycloak).
2. **RAG** — `rag_index` (BGE-M3 → Qdrant) + `rag_search` (vector search → BGE-rerank).
3. **LLM через профиль** — `chat(profile="research")` уходит на **DeepSeek** (политика:
   исследования → DeepSeek), structured output = ровно 3 действия.
4. **Cost + квоты** — каждый вызов метрится; в ответе видно `cost_rub` и остаток
   лимита (5M/сессия, 25M/неделя).

Это ровно те «20 минут зачем + руки»: студент видит auth → retrieval → rerank →
LLM → метрику стоимости в одном прогоне.

## Запуск

```bash
pip install fastmcp
export MCP_URL="https://mcp.example.ru/mcp"      # твой курсовой MCP
export MCP_TOKEN="<JWT от Keycloak>"             # на лекции — тестовый токен
python agent.py
```

## Что покажет

- сколько отзывов проиндексировано,
- топ-жалобы (после rerank),
- **3 конкретных действия на понедельник** от агента,
- стоимость прогона в рублях и остаток недельного лимита.

## Файлы
- `agent.py` — сам агент (≈80 строк, читается на лекции целиком).
- `sample_reviews.jsonl` — синтетические отзывы (открытые данные, без ПДн).
- `eval.yaml` — мини-eval: проверяем, что агент находит реальную боль и даёт
  выполнимые действия (грейдер — LLM-as-judge, см. скилл `eval-generator`).
