Потоки и связи (ключевые)
1Вход: Desktop-чат → сайдкар (127.0.0.1) → ABOP /api/* под JWT (RBAC/ABAC)
2Подбор: текст → /api/agents/match (лексика+семантика) → «куда результат?»
3Прогон: Data Plane → runner (grounded, self-host Qwen) → находки по схеме из БД
4Governance: конверт автономии + HITL → внешнее действие только после подтверждения
5Доставка: OUT-узлы → Redmine/почта/BookStack по шаблону отчёта; агент адресен (Identity Map)
6Аудит: provenance-трасса + метрики/логи в Grafana/langfuse; расписания через планировщик
