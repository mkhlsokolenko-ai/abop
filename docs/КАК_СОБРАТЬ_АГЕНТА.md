# Как собрать агента и запустить его — пошагово, простыми словами

> Инструкция для того, кто видит ABOP впервые. Никакого кода. Читай сверху вниз и нажимай по шагам.
> В конце — раздел «Если что-то пошло не так» и шпаргалка.

---

## Сначала — 8 слов, которые надо понять (одна минута)

Представь, что ты **нанимаешь сотрудника** и объясняешь ему работу. В ABOP всё так же:

| Слово | Что это простыми словами | Пример |
|---|---|---|
| **Коннектор** | Розетка к чужой системе (откуда брать данные) | Подключение к базе оплат, к почте, к CRM |
| **Рецепт** | Инструкция «как приготовить данные», чтобы агент их понял | «Из таблицы оплат сделай чистый список» |
| **Навык** | Одно умение | «Сверять оплаты с документами» |
| **Семья** | Отдел компании | «Финансы» |
| **Роль** | Должность в отделе | «Бухгалтерия / закрытие» |
| **Агент** | Сотрудник = роль отдела + её навыки | «Сверщик оплат» |
| **Конверт** | Рамка безопасности: что агенту МОЖНО, а что НЕЛЬЗЯ | «Читать — да, платить — только с разрешения человека» |
| **Лимб** | Архив уволенных агентов (выведенных из работы) | Туда отправляют, а не удаляют насовсем |

**Золотое правило порядка:** сначала ДАННЫЕ (розетка + рецепт) → потом СОТРУДНИК (агент из роли и навыков) → потом ЗАПУСК и РЕЗУЛЬТАТ.

---

## Что мы соберём (сквозной пример)

Соберём агента **«Сверщик оплат»**. Его работа: взять оплаты и документы из систем компании, **найти где не сходится** (оплата без документа, недоплата, двойная оплата, скидка, которую менеджер забыл откатить) и отдать список человеку.

Поехали. Экраны ABOP слева в меню: **Обзор · Загрузка из LUDA 2 · Граф · Навыки · Данные · Агенты · Настройки**.

---

## ШАГ 1. Открой ABOP

1. Открой браузер: **http://127.0.0.1:8091**
2. Слева — **меню** (Обзор, Граф, Навыки, Данные, Агенты…). Это твои комнаты.
3. Если только что что-то меняли в программе — нажми **Ctrl+F5** (обновить страницу начисто).

> 🟢 Видишь меню слева — всё хорошо, иди дальше.

---

## ШАГ 2. Подключи ДАННЫЕ — «розетку» (коннектор)

Меню слева → **Данные** → вкладка **Коннекторы**.

1. Нажми **＋ подключить**.
2. Выбери **тип источника** — список большой, выбирай по тому, ГДЕ лежат данные:
   - **CSV / Excel (xlsx)** — файл-таблица.
   - **PostgreSQL / SQLite** — база данных.
   - **REST API** — чужая программа отдаёт данные по ссылке (1С, CRM, трекер, почта).
   - **Текст / PDF** — документы (договоры, акты).
   - **Векторная БД** — «умный поиск по документам» (база знаний).
3. Впиши **путь или ссылку** (поле подпишется само).
4. Нажми **Тест-прогон** — система прочитает пару строк и скажет «Источник доступен, строк: N».
5. Нажми **Подключить**.

> 🟢 «Источник доступен» — розетка работает.
> 🔴 «Ошибка: источник недоступен» — проверь путь/ссылку (см. конец).

**В примере** уже подключены: оплаты и документы (из хранилища), почта, трекер задач, вики с договорами, CRM.

---

## ШАГ 3. Напиши РЕЦЕПТ — «как приготовить данные»

Сырые данные агент не понимает. Рецепт превращает их в **чистый список**.

Вкладка **Рецепты** → **＋ рецепт**. Слева — редактор, справа — **Предпросмотр**.

1. **Источник:** выбери коннектор из Шага 2.
2. **Сущность** — ЧТО это за данные: `transaction` (оплаты/счета), `document` (документы/договоры), `customer` (клиенты), `issue` (задачи), `email` (письма).
3. **Поля (map):** какие колонки взять и как назвать. Строка = «поле ← откуда брать». Можно указать тип: деньги, число, дата.
4. **Правила (rules):** фильтры и защита. Например `сумма > 0` (выкинуть мусор), `спрятать почту` (маска личных данных).
5. Нажми **Проверить** — справа появится: ✓ сколько записей, ⚠ сколько выкинуто, и сами чистые записи с пометкой откуда взяты.
6. Всё хорошо → **Сохранить рецепт**.

> 🟢 «✓ N записей» и аккуратные строки — рецепт готов.
> 🔴 «0 записей» — имена колонок в «Поля» не совпали с источником.

> 💡 Рецепт делается **на тип данных (сущность), а не под конкретного агента**. Это общий склад — с него берут все агенты.

---

## ШАГ 4. Посмотри НАВЫКИ — «умения»

Меню → **Навыки**. Кликни навык — откроется карточка:
- **Когда применять / Метод (по шагам) / Что должно получиться / Анти-паттерны** — методичка умения.
- **Безопасность:** режим (только читать / писать / действие), выход наружу, «числа только из источника».
- **Источники данных:** какие сущности навык берёт и **из какого рецепта**. Если написано «нет рецепта — создать» — вернись в Шаг 3 и сделай рецепт для этой сущности.

> 🟢 У навыка «Источники данных» показывают сущность и зелёный рецепт — умение обеспечено данными.

**В примере:** навык **«Сверка регистров»** берёт `transaction` (оплаты) и `document` (документы). Рецепты для них уже есть.

---

## ШАГ 5. Собери АГЕНТА на канве (главный шаг)

Меню → **Граф**. В центре — холст, слева — **палитра** (ящик с деталями).

1. В палитре найди группу **«Роли (семьи)»**. Там реальные должности по отделам: Финансы, Аналитика, Менеджмент и т.д.
2. Выбери роль — для нашего примера **«Бухгалтерия / закрытие»** (отдел Финансы) — и **перетащи её мышкой на холст**. Появится **узел-агент**.
3. Роль сама приносит свой набор навыков (для бухгалтера — сверка, закрытие периода, объяснение отклонений).
4. Слева в палитре возьми **источники** (оплаты, документы) и перетащи на холст, соедини стрелкой с узлом-агентом — «агент берёт эти данные».
5. Добавь узел **«Вывод»** в конце — куда положить результат.

> 🟢 На холсте цепочка: `[оплаты] → [Агент-бухгалтер] → [вывод]` и `[документы] → [Агент-бухгалтер]` — сборка готова.
>
> 💡 Не хочешь собирать руками? Нажми **«＋ LLM-черновик потока»**, опиши словами («сверь оплаты с документами, найди расхождения») — система нарисует черновик.

---

## ШАГ 6. Проверь свой парк агентов — экран «Агенты»

Меню → **Агенты**. Это как экран «Данные», только про сотрудников.

- Вверху переключатель **«В работе (N)» / «Лимб / архив (N)»**.
- **«В работе»** — живые агенты. Каждый — карточка: имя, роль·семья·статус·автономия.
- **Клик по карточке** → откроется **подробная карточка агента** (справа выезжает панель): роль и семья, миссия, **конверт безопасности** (режим/выход/цитирование + уровень автономии), **список навыков**, **источники данных** (какие сущности и из каких рецептов берёт), **переходы** (в какие смежные роли отдела агент может «переобуться»).
- Кнопки на карточке:
  - **В Лимб** — отправить в архив (агент выведен из работы, но не удалён — можно вернуть).
  - **Восстановить** (в Лимбе) — вернуть агента в работу.
  - **Удалить** — стереть насовсем (для черновиков/ошибок).

> 💡 **Лимб** — это «отпуск без содержания» для агента: он не работает, но его история сохранена. Удаление — совсем в корзину. Правило: сомневаешься — отправляй в Лимб, не удаляй.

---

## ШАГ 7. Проверь ПАСПОРТ (конверт безопасности)

Перед запуском посмотри «должностную инструкцию» агента (в его карточке или на экране Паспорт):
- **Автономия** — насколько агент самостоятелен (A0 самый зажатый … A4 самый свободный). Она **не выше**, чем разрешил контракт из LUDA.
- **Точки HITL** — где агент ОБЯЗАН спросить человека (перед отправкой письма, переводом денег).
- **Резидентность** — данные не уходят наружу, личные данные маскируются.

> 🔴 Красный баннер «превышение конверта» — агент хочет больше прав, чем можно. Запуск заблокируют. Убери лишние права.
> 🟢 «DoD ✓» и автономия «≤ контракт» — можно запускать.

---

## ШАГ 8. ЗАПУСТИ и смотри результат

1. Нажми **[Запустить]** (или переключи линзу на **«Запускаю»**).
2. По узлам побегут **«волны»** — агент работает по шагам: берёт данные → применяет навык → складывает находки.
3. Дошёл до **точки HITL** — остановится и **спросит тебя** («Подтвердить?»). Жмёшь «Подтвердить» или «Отклонить».
4. В конце **агент-аудитор** сам проверит результат по чеклисту и честно скажет, что получилось.
5. Результат — в узле **«Вывод»**. В нашем примере это **список расхождений**: оплата без документа, недоплата, двойная оплата, забытая скидка — с суммами и ссылкой на источник.

> 🟢 Готово! Ты собрал, проверил и запустил ИИ-сотрудника под контролем безопасности.

## Как это всё связано (одна картинка словами)

```
Чужая система (1С, почта, CRM, файл)
      │  через КОННЕКТОР (розетка)
      ▼
РЕЦЕПТ (готовит данные) ─► СУЩНОСТЬ: чистый список (оплаты, документы) — общий склад
      ▼
НАВЫК берёт со склада нужные поля и применяет умение
      ▼
АГЕНТ = роль отдела + навыки (живёт на экране «Агенты»; можно в Лимб/вернуть/удалить)
      ▼
Запуск волнами → точки HITL (спросить человека) → аудитор проверяет → ВЫВОД (результат)
      ▲
   КОНВЕРТ (рамка безопасности) — следит сверху: что можно, что нельзя
```

## Если что-то пошло не так

| Что видишь | Что это значит | Что делать |
|---|---|---|
| «Источник недоступен» при тесте коннектора | Розетка не втыкается | Проверь путь к файлу / ссылку. Для базы — логин-пароль. |
| «0 записей» в предпросмотре рецепта | Данные есть, но поля не совпали | В блоке «Поля» проверь имена колонок — должны совпадать с источником. |
| У навыка «нет рецепта — создать» | Умению неоткуда брать данные | Вернись в Шаг 3, сделай рецепт для этой сущности. |
| Красный баннер «превышение конверта» | Агент хочет больше прав, чем можно | Убери лишние права / понизь автономию. |
| Агент «завис» на середине | Это точка HITL — он ждёт ТЕБЯ | Нажми «Подтвердить» или «Отклонить». |
| Случайно вывел агента из работы | Он в Лимбе, не потерян | Экран «Агенты» → вкладка «Лимб» → «Восстановить». |
| Пустой экран / кнопки не реагируют | Старая страница в кэше | Нажми **Ctrl+F5**. |

## Шпаргалка (повесь на стену)

1. **Данные → Коннекторы** — воткни розетку, нажми «Тест-прогон».
2. **Данные → Рецепты** — приготовь данные, «Проверить» → «Сохранить».
3. **Навыки** — проверь, что у умения источник привязан к рецепту.
4. **Граф** — перетащи роль из «Роли (семьи)» на холст → узел-агент, подключи источники.
5. **Агенты** — тут твой парк: клик по карточке = подробности; кнопки В Лимб / Восстановить / Удалить.
6. **Паспорт / Конверт** — проверь безопасность (нет красного баннера).
7. **[Запустить]** — смотри волны, отвечай на вопросы HITL, забери результат из «Вывода».

> Готово. Если справился — ты только что собрал ИИ-сотрудника под контролем безопасности. 🎉
