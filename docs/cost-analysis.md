## 2. Квота студента

Трёхуровневый лимит (реализован в MCP, `server/db.py`):

- **5M токенов / сессия**
- **5 сессий / неделю**
- **= 25M токенов / студента / неделю**

## 3. Стоимость на объёме курса

### Вариант A — старый плоский лимит (2M/студента, разово)

30 студентов × 2M = 60M токенов за курс. Через API — **копейки** (DeepSeek ~$9,
RouteAI ~5k₽). Self-host тут не окупается (API в 100× дешевле аренды GPU).

## 4. Self-hosted Qwen3.8-27B: выбор карты

Qwen3.8-27B — open-weight, влезает в один GPU в кванте:

| Квант | Веса | Мин. VRAM | Качество кода | Concurrency/контекст |
|---|---|---|---|---|
| FP16 | ~54GB | не влезает в 48/32 | эталон | — |
| **int8** | ~27GB | нужна **48GB** | near-lossless | хорошо |
| **int4 (AWQ/GPTQ)** | ~14GB | хватает **32GB** | небольшая потеря | тесно на 32GB |

### RTX 6000 48GB (уже арендована, $0.60/ч) — рекомендуемая
- int4 (~14GB) → ~34GB под KV-кэш; или **int8** (лучше по коду).
- Контекст: **не ставь 1M** (KV съест память) — `--max-model-len 32768…131072`.
- Concurrency: ~5–15 одновременных на умеренном контексте.
- Цена: $0.60/ч → **$432/мес** → ~**$1 730 за семестр**. В ~3.6× дешевле RouteAI на код-нагрузке.

### 32GB — бюджетный вариант
- Только **int4** (int8 не влезает: ~27GB весов + KV → задыхается).
- Контекст ~32k, concurrency ниже, раньше очередь на пике.
- Экономия ~$0.2/ч ≈ **$150/мес**. Оправдана при **асинхронной** нагрузке.
- Для живого потока с пиком в 90-мин окне — лучше 48GB (int8 + запас concurrency).

### Пропускная способность и риск
- Одна карта ≈ **500–1500 ток/с** (vLLM, int4, батчинг).
- Хватает на домашку, размазанную по неделе. **Синхронный пик** (30 студентов в
  одном лекционном окне) → очередь. Варианты: 2-я карта на пик, или на демо-парах
  гнать через RouteAI.

### Ферма MI50 (ROCm) — есть в проекте Red Team AI
- 2×MI50 (64GB) держат FP16, или int4 на одной. Маржинальная стоимость = электричество
  (~$110/семестр).
- **Но:** gfx906 выкинут из ROCm 6+, современный vLLM хочет свежий ROCm → возня
  (старый ROCm / llama.cpp-форки), скромный throughput. Заложи время на ops.

## 5. Про «второй аккаунт Claude за $100»

- $100/мес = **Claude Max** (подписка на **один логин**), это **лимиты сообщений**, а
  не токен-бюджет и **не API-ключ**.
- **Раздать 30 студентам через MCP/RouteAI нельзя** — шлюзу нужен API-ключ
  (pay-as-you-go с метрингом), подписку не проксируешь по студентам.
- Правильное применение: **для лектора** — Claude Code, сборка pet-проекта до старта
  (принцип Осадчего), ревью, демо. Для своей тяжёлой работы $100 Max — отличная сделка.

## 6. Рекомендованная конфигурация

| Нагрузка | Backend | Почему |
|---|---|---|
| Кодинг студентов (`profile=code`) | **self-hosted Qwen3.8-27B**, RTX 6000 48GB | output-heavy → фикс-цена GPU дешевле API |
| Исследования (`profile=research`) | **DeepSeek API** через RouteAI | дёшево даже на 25M/нед |
| Fallback / разнообразие / демо | RouteAI-каскад | ноль ops, много моделей |
| Лектор (сборка, ревью, демо) | **Claude** ($100 Max, свой аккаунт) | качество, не на студентах |
| Корпоративный bootcamp (NDA) | **self-host обязателен** | данные не уходят наружу |

Итого по деньгам за семестр (30 студентов): аренда RTX 6000 ~**$1 730** + DeepSeek на
research ~**$2 000** + $100 Max лектору = **порядка $4–5k за весь курс** вместо
десятков тысяч на Claude-для-всех.
