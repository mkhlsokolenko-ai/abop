# DESIGN.md — портал AI Product Engineer

Направление зафиксировано по скиллу `design-direction` (sLAVA), проверено чек-листом
`auditor-frontend-ui-ux` и методикой `LUDA_DESIGN_AUDIT` (единая палитра, WCAG-контраст,
4/8-сетка, один `.btn`, полная тёмная тема, анти-slop). Brownfield: система уже была
(тёмная red-team.tech) — здесь она осознанно переносится в EdTech-направление.

## 1. Направление
Аудитория — студенты курса (вчерашние джуны/продакты) и лектор. Тон: **дружелюбная
обучающая платформа**, не «дашборд безопасника» и не «AI-slop». Атрибуты: `warm,
spacious, academic, trustworthy`. Поверхность — internal LMS (рабочее пространство, не
маркетинг), поэтому плотность средняя, воздуха много, навигация — постоянная.

## 3. Референс-борд (что конкретно заимствуем)
- **Coursera (learner/course home)** — *левый сайдбар-навигация* рабочего пространства +
  крупная кнопка **«Продолжить»** как главный CTA + кольцо общего прогресса. Чистая
  иерархия и воздух. → берём: sidebar-layout, continue-hero, progress-ring.
- **Skillbox / GeekBrains (ЛК студента)** — программа как *дерево модулей с галочками/%*,
  секции навигации с иконками, статус-чипы у заданий. → берём: иконки в навигации,
  чипы статусов, роадмеп с отметками пройденного (уже есть).
- **Stepik (курс)** — левый рельс со шагами, компактные карточки, empty-states. → берём:
  вертикальная навигация, аккуратные пустые состояния.
- **Notion (референс командного центра лектора)** — тёплый нейтральный фон, inline-правка
  таблиц, лёгкие тени. → берём: inline-edit, tiles, спокойные карточки.

Анти-slop-гейт: каждый референс оправдан ролью (навигация/CTA/прогресс/таблица), а не
«красиво».

## 4. Дифференциация (чтобы не раствориться в SaaS-супе)
1. **Инженерный контур в дружелюбной оболочке** — JetBrains Mono на всех числах (токены,
   cost, КТ-баллы, RAG-коллекция) поверх тёплой EdTech-палитры: узнаётся как «курс для
   инженеров», а не generic-LMS.
2. **Cost/квоты как первоклассная сущность** — то, чего нет у Coursera/Skillbox: лидерборд
   по токенам, cost-плитки, командный центр с сигналами. Это ownable-фича курса.

## 5. Компоненты
- **Навигация:** левый сайдбар (220px) с иконками и группами на десктопе; топ-бар с
  выпадающим меню на мобиле. Топ-бар везде несёт бренд + тему + профиль.
- **Кнопки:** один `.btn` + `.primary/.sm`; радиус `--r-m`; `focus-visible` кольцо.
- **Карточки:** `--bg-1` + `--border-1` + `--shadow`, радиус `--r-l`.
- **Модалки:** заголовок слева, действия справа (`justify-end`), вторичная — outline.
- **Состояния:** hover/focus-visible/disabled/loading/empty у каждого интерактива;
  клик-карточки получают `role/tabindex`.

## 6. Что закрывает аудит (P0/P1)
- Контраст мета-текста подтянут под AA (ink-3).
- `focus-visible` глобально; иконочные кнопки — `aria-label`.
- 4/8 спейсинг-шкала и токен-радиусы вместо литералов «на глаз».
- Полная тёмная тема из общих токенов (нет жёстко-светлых панелей).
