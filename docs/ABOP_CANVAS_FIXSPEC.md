# ABOP — Fix-Spec Канвы (прототип v3): дизайн + юзабилити + продукт

**Что это:** единый приоритизированный список правок Канвы (линзы Строю/Прогон/Эксплуатирую/Конверт) прототипа v3, сведённый из многоагентного аудита (9 линз: консистентность уровней · Ops наследует граф-движок · правая шторка = как Инспектор · выравнивание геометрии · ясность фильтров/режимов · юзабилити и мёртвые элементы · брендкит/AI-slop · 2-мин тест · продукт/логика/поток за рамками дизайна).
**Источник:** аудит по реальной разметке `ABOP v3 standalone-src.dc.html` + брендкит. Ссылки на строки — по этому файлу.
**Статус:** v1.0 — к внедрению. Модель UI — канва-центричная ([[ADR-030]]).

## 1. Резюме

**Вердикт: НЕ готова.** Каркас есть, дизайн-язык ядра соблюдён (палитра индиго, #16203a, семафор, Эйп), но Канва проваливается по консистентности уровней, наследованию движка Ops и завершённости потока. Средние оценки аудиторов 4–5/10, 2-мин тест 6/10 — ниже порога 7.

**Оценки по линзам:** Консистентность/уровни 4 · Ops наследует движок 3 · Правая шторка 4 · Геометрия 4 · Фильтры/режимы 4 · Юзабилити/мёртвые 5 · Брендкит/slop 6 · 2-мин тест 6 · Продукт/логика 5.

**Корневые проблемы:**
1. **Плоская иерархия управления.** Топбар сваливает 4 уровня (workspace / граф / сценарий / lifecycle) в один flex-ряд без разнесения; линза, сценарий, слой, фильтр выглядят одинаково при разной природе. Нарушение ожидания владельца №1.
2. **Ops на чужом движке.** Карта процесса — flex-плитки со стрелками-глифами «→», а не холст-граф с SVG-рёбрами и портами. Две несогласованные модели графа → ветвления/циклы невыразимы, governance узла теряется. Нарушение №2.
3. **Поток не замкнут по-настоящему.** Ключевые переходы (Реестр/Живые/Здоровье/Граф агента/В прод) кончаются тост-заглушкой; переключение линзы/сценария молча затирает несохранённые правки; save-chip имитирует persistence.
4. **Governance невидим в рабочем контексте.** Конверт виден только в верхней полосе и Инспекторе; на узлах/рёбрах Ops и на прогоне — нет прав/egress/HITL/версии без клика.
5. **Геометрия «на глаз».** Ширины 200/262/320, карточки 208/214, паддинги 15/18/20, бордеры .07/.08/.1 — нет единой сетки токенов.

## 4. За рамками дизайна: продукт и логика

**Незавершённость потока (тост-заглушка vs реальный экран)**
- **[blocker]** *Разрыв:* переключение линзы/сценария (`go` 3302, `loadScenario` 4196, `revise`) молча затирает `canvasDirty` — правки теряются, save-chip имитирует persistence через setTimeout. → *Фикс:* guard-modal при `s.canvasDirty` на любом переходе, меняющем tree: «Сохранить / Отменить / Продолжить без сохранения». Save-chip отражает реальное состояние стора.
- **[blocker]** *Разрыв:* `ctxOpenGraph`/`openGraph` (3277, 3205) делают `loadScenario+lens:'build'+showToast` — подменяют несохранённый граф чужим сценарием, отклик = тост, нет пути назад. → *Фикс:* сохранять `fromOps:{crumb,tileId}`, показывать в крошке «Эксплуатирую / <процесс> / Граф агента ▸» + кнопку «↑ к процессу». Убрать тост как единственный отклик.

**Недостающие состояния**
- **[gap]** Нет error/нет-прав/оффлайн: `runCheck` при провале только тост 4366; оператор без права деплоя видит «В прод»/«Посадить» активными; Ops-данные появляются мгновенно (нет skeleton); нет экрана «HITL отклонён». → *Фикс:* envelope-error для runCheck; disable+подсказка на lifecycle-кнопках по RBAC-флагу; skeleton-плитки Ops; дровер «Прогон закрыт по отклонению HITL» + «Пересобрать».

**Видимость governance/конверта**
- **[gap]** *Разрыв:* конверт почти невидим на графе — права/egress только при выборе узла, чипы могут быть скрыты (`n.chipsShown`); ребро не несёт тип связи визуально. → *Фикс:* на карточке узла ВСЕГДА микро-бейдж уровня прав (L1-L4) + иконка egress-наружу независимо от `chipsShown`; на ребре пилюль-ярлык типа у mid-точки + жёлтая метка при `kind='hitl'`; конверт-полоса подсвечивает узлы-нарушители по клику.
- **[gap]** *Разрыв:* аудит/ре-аттестация досягаемы только из алертов; «Посадить агента» 1254 не проверяет периметр участка ⊆ контракт (ядро LUDA scope⊆creator). → *Фикс:* в контекст-панель Ops строку «Конверт: ре-аттестован <дата> · периметр <N систем>» + «История/аудит»; на «Посадить агента» — префлайт-проверка LUDA ДО открытия deploy-modal.

**Привязка данных**
- **[gap]** *Разрыв:* часть KPI — хардкод без provenance («Стоимость флота 38 ₽/сут» 3034, `costSpent` 1240, `dodDrift −6%», спарклайны) — не сойдутся с суммой per-instance `i.cost`. → *Фикс:* считать «Стоимость флота» как сумму cost_journal живых экземпляров за `healthWindow` ЛИБО пометить «demo»; `dodDrift`/sparks привязать к окну.

**Версионирование**
- **[gap]** *Разрыв:* бейдж бинарен «черновик|в проде» (3324); модель draft→v1→v2→prod невидима; `revise()` теряет цепочку; `deployVersions` не связаны с tree. → *Фикс:* версия рядом с `agentBadge` («черновик от v2» / «v3 · в проде»); в reviseMode-баннере (773) «Сравнить с прод-версией» (diff узлов/прав); связать `deployVersions` с tree.

**Масштаб / крайние случаи**
- **[gap]** *Разрыв:* Ops flex-ряд на 20+ операциях = простыня, стрелки «→» ломаются при переносе; Канва — только `toggleFull`, нет зума/мини-карты, на 50 узлах налезают; крошки без предела вложенности. → *Фикс:* Ops → canvas-движок с зумом/панорамой; Канве zoom-контролы + мини-карта при `surfaceW>N`; крошки — сворачивать середину в «…» при глубине >3.
