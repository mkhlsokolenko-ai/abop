# Альтернативы: Kimi / DeepSeek / Qwen агенты vs Claude

Вопрос: на чём гонять агентов студентов — и как в это вписан Claude.

## Ключевой факт: RU-доступ

Claude API из РФ напрямую недоступен без прокси — **именно поэтому в архитектуре стоит
RouteAI** (OpenAI-совместимый шлюз с RU-доступом). Через него идут Qwen / DeepSeek /
GLM / Kimi. Claude-подписка ($100 Max) работает у лектора через claude.ai / Claude Code,
но на студентов через API её не раздать (см. cost-analysis §5).

## Сравнение под роли курса

| Модель | $/1M (вх/вых) | Сильна в | Роль |
|---|---|---|---|
| **DeepSeek V4-Flash** | 0.14 / 0.28 | дёшево, research, reasoning | **research (дефолт)** |
| **DeepSeek V4-Pro** | 0.435 / 0.87 | сложный research | research (качество) |
| **Qwen3.8-27B** | 0.35 / 2.55 | код, агентские задачи, open-weight | **code + self-host** |
| **Kimi K2.6** | 0.95 / 4.00 | агенты, длинный контекст | резерв/сравнение |
| **Claude Opus 4.8** | 5.00 / 25.00 | максимум качества, длинные агентские | **лектор** |

## Почему такой расклад

- **DeepSeek на research** — на порядок дешевле всех, отлично тянет discovery, генерацию
  спек, судью в eval. При 25M/нед research почти ничего не стоит. → политика «исследования
  только на DeepSeek».
- **Qwen3.8-27B на код** — open-weight (⇒ self-host на своей RTX 6000, output бесплатен),
  заточен под код и агентов, 1M контекст. Для output-heavy кодовых агентов это решает
  экономику (см. cost-analysis §3–4). → политика «кодинг на Qwen».
- **Kimi** — хорош, но дороже DeepSeek и не open-weight под наш self-host; держим в
  каскаде RouteAI как альтернативу для сравнения (педагогика: «учим сравнивать модели»).
- **Claude** — эталон качества и длинных агентских трасс, но per-token недоступен для
  студенческого объёма (десятки тысяч $). Оставляем лектору для сборки эталонного
  pet-проекта, демонстраций «как надо» и ревью.

## Педагогический аргумент (принцип №7 курса)

«Учим протоколам, а не фреймворкам/одной модели». MCP абстрагирует backend, поэтому
студент **сравнивает** модели на одной задаче (Qwen local vs DeepSeek vs Kimi vs, у
лектора, Claude) и обосновывает выбор в ADR. Это и есть навык FDE — не «знаю одну
модель», а «умею выбрать и померить».

## Итоговая раскладка агентов

- **Кодовый агент (OpenCode)** → `profile=code` → self-hosted Qwen3.8-27B (fallback DeepSeek).
- **Исследовательский агент / discovery / eval-судья** → `profile=research` → DeepSeek.
- **Разнообразие / отказоустойчивость** → RouteAI-каскад (Qwen/DeepSeek/Kimi/GLM).
- **Эталон и ревью** → Claude у лектора.
