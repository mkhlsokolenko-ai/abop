**Три вещи, которые надо сделать до любого показа наружу:**
1. **Стенд открыт в интернет без аутентификации** — `KEYCLOAK_JWKS_URI` пуст, любой анонимный запрос = `dev (admin)`: читаются пользователи Keycloak (`/api/admin/users`), удаляются агенты (`DELETE /api/agents/*`), меняется LLM-эндпоинт (`POST /api/admin/llm`). **[live]**
2. **Web: «Удалить» на карточке агента — один клик, без подтверждения и undo, жёсткий DELETE всех версий.** В ходе теста так был удалён демо-агент «Дайджест задач» (`mailtasks-daily-2026.v11`); восстановлен (см. §6). **[live]**
3. **Web: «＋ Новый прогон» — симуляция.** План волн одинаков для любой цели («Собрать данные по рынку и транзакциям → Посчитать экономику → Синтез и письмо заказчику», ≈0.42 ₽), `startRun` не вызывает API, результат — константы. Главный CTA продукта опровергает обещание онбординга. **[live+код]**

### Desktop
**Рейл:** Чат · Источники · Мои агенты · [Граф — только lecturer/admin] · Кабинет · Распознать. Каждый клик по рейлу **пересоздаёт модуль** (`panel.innerHTML=""`) — теряются черновик, открытые шторки, карточки цепочек.

| Сценарий | Разрыв |
|---|---|
| Первый запуск → вход | композер мёртв без треда; ошибки говорят «нужен вход через GitHub», кнопка — «Войти в ABOP»; `POST /api/auth/login` блокирует до 300 с без отмены; пилюля расхода в шапке не обновляется после входа |
| Новый чат → агент → результат | **пять входов** для запуска агента (карточка решения, зелёный чип, шторка 🕸, «Мои агенты», цепочки) и **две поверхности результата** (чат / `#result` внизу «Моих агентов»); нет стопа/отмены; Enter во время стрима запускает второй стрим |
| Цепочка → HITL → доставка | конструктор: только `chat/email/redmine` — **BookStack из демо-гайда отсутствует**; запуск без задачи/контекста, «цепочка работает…» без прогресса; результат живёт только в памяти — уход в «Мои агенты» стирает карточку; «Подтвердить все» одобряет всю очередь одним кликом; `hitl_id` вырезан сайдкаром → фолбэк подтверждает все pending-заявки агента |
| Мои агенты | без логина 401 → ложное «У вас пока нет своих агентов»; ошибки удаления глотаются |
| Граф | `agent_id` приводится к числу (`+e.target.value` → NaN) — привязка реального агента ломается; связи нельзя удалить; «Проверить» отвечает «✓ Исполнимо», хотя исполняются только узлы `agent` |
| Источники / OCR | распознанный текст выбрасывается: «откройте чат и приложите через 📎» (📎 — выбор файла) |
| Кабинет | «Персона» пишется в localStorage и нигде не читается; политика ролей и «источники: 3» — хардкод |
