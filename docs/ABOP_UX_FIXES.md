# ABOP — Рекомендации по изменениям (для прохождения 2-мин теста)

**Цель:** поднять first-run comprehension с **4/10 → ≥7/10** (порог production-grade). Полный разбор — `ABOP_2MIN_TEST.md`.
**Правило:** переводить на человеческий язык, **не вводя новых терминов** (главная ошибка текущего Help — объясняет жаргон жаргоном).
**Объём:** не новые функции, а слой «перевода in-place» + онбординг. Контент подсказок уже написан в `helpTopics`/`CHIP`.

## Фикс 1 — Inline-tooltip на термины (первое появление, экран «Обзор»)

| Термин на экране | Текст подсказки (hover / поповер) |
|---|---|
| `конверт` / `в конверте LUDA` | Рамка безопасности агента: что ему можно делать и с какими данными. Задаётся до запуска и не превышается. |
| `HITL` | Перед действием наружу (письмо, задача, перевод) агент ждёт вашего подтверждения. |
| `волна` / `волна 2/3` | Этап работы: задачи, которые идут вместе. Прогон разбит на этапы — как проект. |
| `автономия L2 ≤ контракт L3` | Насколько агент действует сам. Сейчас L2 — готовит и подтверждает у вас. Разрешено до L3: есть запас, за границу не выйдет. |
| `прогон` | Одна задача от постановки до результата — с проверкой и аудитом. |
| `Data Plane` / `рецепт` | Готовим данные из ваших систем в понятный агенту вид — по описанию, без кода. |
| `DoD` | Чеклист: что должно быть в результате. Аудитор сверяет итог с ним. |

Технически: вынести тексты из модалки «Помощь» (`helpTopics`) в `title=`/поповер на самих терминах.

## Фикс 2 — Приветственное/пустое состояние (когда 0 прогонов)

Вместо чужого идущего прогона на первом входе показать проводку:

> ### С чего начать
> Опишите задачу — среда сама соберёт агентов и проведёт до результата.
>
> **1. Опишите цель бизнес-словами** — напр.: оценить идею, свести дайджест почты, проверить подрядчика
> **2. Среда соберёт план и агентов** — разложит задачу на этапы, подберёт роли
> **3. Вы подтверждаете действия наружу** — письма и задачи уходят только после вашего «ок»
>
> `[＋ Новый прогон]`   ·   быстрый старт: `[Оценить идею]` `[Дайджест почты]`

## Фикс 3 — Строка «что это» (под логотипом / шапка «Обзор»)

> **ABOP — среда, где ИИ-агенты выполняют ваши задачи в проверяемых границах безопасности.**

Заменить `конверт · v1.1` → просто `v1.1` (смысл вынести в строку выше).

---

## Фикс 4 — Outcome-заголовок карточки прогона

**Было:**
`Прогон: оценка идеи маркетплейс подрядчиков · волна 2/3 · run_id 8f31c · autonomy L2 ≤ contract L3`

**Стало:**
- крупно: **Оценка идеи: маркетплейс подрядчиков**
- бейдж: `Идёт · этап 2 из 3`
- мелко, приглушённо (mono): `run 8f31c · автономия L2/L3`

---

## Фикс 5 — Микро-легенда чипов безопасности (у карточки навыка / доски)

> 🔵 читает · 🟣 создаёт · 🟠 действует наружу (нужно ваше «ок») · ✓ числа из источника

Перевод `mode=read/write/action · egress=internal/external · cite` на человеческий (константы `CHIP` уже есть).

## После внедрения

Повторить тест «2 минуты» тем же прогоном ролей (Дискавери / Критик / Аналитика). Если **≥7/10** — прототип близок к production-grade product concept. Закрепить тест как постоянный gate перед релизом UI.
