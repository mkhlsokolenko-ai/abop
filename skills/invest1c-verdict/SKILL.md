# Заключение по цепочке расследования (invest1c-verdict)

Ты превращаешь прослеженную цепочку в заключение, которое поймёт главбух: где именно рвётся операция, на какую сумму, каким налоговым/нормативным риском это грозит и что делать. Норму НК не пересказывай по памяти — подтягивай её из корпуса (RAG) и цитируй.

## Когда применять
- Есть цепочки-расследования из `invest1c-trace` со звеном-разрывом.
- Нужно оценить риск разрыва по НК РФ гл.21 и дать проверяемую рекомендацию.
- Перед выдачей наружу — оформить заключение под подтверждение человека.

## Метод (пошагово)
1. **Возьми цепочку** и её звено-разрыв (нет счёта-фактуры / нет оплаты / расхождение сумм).
2. **Что не сходится**: сформулируй разрыв одной фразой + сумма расхождения в рублях.
3. **Откуда**: сошлись на конкретные документы звеньев (реализация, оплата, счёт-фактура) и их номера/даты.
4. **Чем грозит**: подтяни норму НК РФ гл.21 из корпуса (счёт-фактура ст.169, вычет ст.171–172, момент определения базы ст.167) — цитируй, а не пересказывай; для оценок стоимости/себестоимости — ФСБУ 5/2019.
5. **Что проверить**: конкретное действие (выставить/запросить СФ, привязать платёж, скорректировать период), а не общий совет.
6. **HITL**: существенные заключения — только под подтверждение человека; наружу (отчёт/письмо) ничего без явного подтверждения.

## Definition of Done
- [ ] По каждой цепочке-разрыву есть заключение: что не сходится / откуда / чем грозит / что проверить.
- [ ] Норма НК гл.21 (или ФСБУ) процитирована из корпуса, а не по памяти.
- [ ] Указана сумма расхождения и затронутые документы звеньев.
- [ ] Рекомендация конкретна и проверяема.
- [ ] Существенные заключения помечены под HITL; наружу без подтверждения ничего не ушло.

## Анти-паттерны
- Не выдумывай норму и номер статьи — только из корпуса (RAG).
- Не давай общих советов «улучшить учёт» — конкретное действие по конкретной цепочке.
- Не отправляй заключение наружу без HITL.
- Не оценивай риск без суммы — существенность считается по деньгам и норме.

## Безопасность
- **mode=write** — формирует артефакт-заключение; наружу — только под HITL.
- **egress=internal** — внутри периметра; внешняя отправка отдельным действием под подтверждением.
- **cite=True** — каждый вывод опирается на документ цепочки и процитированную норму.

## Интеграция
- **Вход**: цепочки из `invest1c-trace`; нормы НК/ФСБУ из корпуса семьи (sLAVA, slava_audit1c_norms).
- **Результат**: заключения по цепочкам с нормой и рекомендацией — под подтверждение главбуха.
- **Handoff**: HITL «главбух-подтверждает-заключение» → отчёт/публикация (действие, dry_run по умолчанию).
