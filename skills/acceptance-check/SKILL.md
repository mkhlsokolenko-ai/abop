# Приёмка заказчика по пунктам проекта (acceptance-check)

Ты отвечаешь на вопрос принимающей стороны: что из заявленного подрядчиком заказчик действительно
принял. Это независимое утверждение о тех же пунктах дорожной карты, а не пересказ отчёта подрядчика.

## Когда применять

- Есть дорожная карта проекта и решения комиссии по приёмке: принято, принято с замечаниями,
  не принято, с датой акта и подтверждёнными часами.
- Нужно понять, совпадает ли картина заказчика с картиной подрядчика, и где именно она расходится.
- Работает вместе с навыком сверки плана и факта: два источника по одному пункту — это норма, и
  расхождение между ними разбирает арбитраж прогона, а не ты.

## Метод

1. **Возьми один проект.** Пункты и решения приёмки разных проектов не смешивай: без предмета работы
   сверка превращается в общие слова.
2. **По каждому пункту возьми решение комиссии.** «Принято» — пункт закрыт. «Принято с замечаниями» —
   пункт в работе: он не закрыт, пока замечание не снято. «Не принято» — пункт сорван, независимо от
   того, что подрядчик считает его сделанным.
3. **Считай часы по актам.** Подтверждённые часы берутся из решения приёмки, а не из отчёта
   подрядчика, и живут в своём поле. Заявленное и подтверждённое — две разные величины: складывать их
   в одно поле нельзя, иначе обычная разница между ними выглядит спором о том же самом числе.
   Разницу показывай в сводке.
4. **Не додумывай за комиссию.** Пункт без решения приёмки — это «не рассматривался», а не «принято»
   и не «не принято». Такие пункты перечисли отдельно.
5. **Каждое замечание — к своему пункту.** Замечание объясняет решение: без него «не принято»
   выглядит произволом и спорить с ним нечем.
6. **Оцени готовность к вводу.** Критичные для ввода пункты, которые не приняты, переносят дату ввода.
   Скажи об этом прямо и назови пункты.

## Чего не делать

- Не пересчитывай статус подрядчика: у тебя своя точка зрения, и она ценна именно своей независимостью.
- Не сглаживай расхождение фразой «в целом соответствует». Если картины расходятся, это должно быть
  видно числом и пунктом.
- Не придумывай подтверждённые часы там, где акта нет.

## Результат

Строгая схема: карточка проекта, сводка по решениям приёмки, список пунктов с решением и замечанием,
пункты без рассмотрения, оценка готовности к вводу и один вывод фразой.
