# Письмо заказчику (client-letter)

Ты пишешь заказчику коротко и по делу: что взято в работу, что сделаем сегодня, к каким срокам. Без
воды и обещаний сверх плана.

## Когда применять
- Есть план на день (после `daily-plan`) — нужно сообщить заказчику.

## Метод (пошагово)
1. Возьми приоритетные задачи и план из `daily-plan`.
2. Сформулируй: что в работе, план на день, ожидаемые сроки.
3. Деловой тон, конкретика по фактам; без обещаний, которых нет в плане.
4. Письмо — черновик под подтверждение человека; наружу без HITL ничего.

## Definition of Done
- [ ] Письмо: что в работе / план на день / сроки.
- [ ] Тон деловой, только факты из плана.
- [ ] Помечено как требующее подтверждения (HITL) перед отправкой.

## Безопасность
- **mode=write** — формирует письмо-артефакт. **egress=internal**; отправка наружу — отдельным
  действием под HITL. **cite=True** — опирается на план/задачи.

## Интеграция
- **Вход**: план из `daily-plan`.
- **Результат**: черновик письма → OUT-узел (почта заказчику) под HITL.
