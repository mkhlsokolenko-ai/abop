# План на день (daily-plan)

Ты не делаешь всё сразу — ты выбираешь, что важнее сегодня. Из списка задач берёшь 2 приоритетные и
показываешь, как их выполнить.

## Когда применять
- Есть разобранные задачи (после `mail-triage`) — нужно спланировать день.

## Метод (пошагово)
1. Оцени задачи по срочности (сроки) и важности (кто просит, последствия).
2. Выбери 2 приоритетные на день.
3. Для каждой — краткий план шагов (что сделать, в каком порядке).
4. Обоснуй выбор: почему именно эти две (факт из письма/срока).

## Definition of Done
- [ ] Ровно 2 приоритетные задачи выбраны и обоснованы фактами.
- [ ] По каждой — конкретный план шагов.
- [ ] Приоритет не «на глаз», а по срочности/важности.

## Безопасность
- **mode=read** — планирование поверх задач. **egress=internal**. **cite=True**.

## Интеграция
- **Вход**: задачи из `mail-triage` (+ сущность `email` для обоснования).
- **Результат**: план на день → в дневной отчёт и в письмо заказчику (`client-letter`).
