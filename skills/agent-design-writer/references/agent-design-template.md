# Agent Design Doc — <название агента>

## 1. Job to be done
Одна фраза: что агент доводит до результата.

## 2. Границы
- Что агент НЕ делает.
- Какие действия необратимы и требуют подтверждения человека.

## 3. Tool surface
На каждый инструмент (через MCP): зачем, вход/выход, обратимость, надо ли гейтить.

## 4. Контекст
- Что в системном промпте (стабильное!). Что подаём per-turn. Prompt caching.

## 5. Память
- Нужна ли долгая память (скилл memory-architect). Short/long-term, дистилляция.

## 6. Деградация
- Недоступна модель (cascade) / пустой retrieval / исчерпана квота — что происходит.

## 7. Наблюдаемость
- Логируем: tool-calls, стоимость, версию промпта. (Трейсы — Langfuse.)

## 8. Eval
- Как поймём, что работает (скилл eval-generator): датасет, грейдеры, пороги.
