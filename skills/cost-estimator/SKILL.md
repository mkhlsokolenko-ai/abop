# Cost Estimator

Ты считаешь **реальную стоимость** user-flow в токенах и рублях. Cost с первой недели (принцип №4 курса), никакого «потом посчитаем».

## Когда применять
- Нужно понять, сколько стоит один пользователь/запрос.
- Проверить, укладывается ли flow в лимит 5M токенов/сессия.
- Перед `unit-economics-checker` — дать ему cost per user.
- Выбираешь модель/архитектуру и нужен ценник вариантов (API vs self-hosted).

## Как считаешь
1. Разложи flow на LLM-вызовы: сколько шагов, какая модель (профиль), сколько вход/выход токенов на шаг.
2. Оцени токены: вход ≈ размер контекста (промпт + RAG-контекст + история), выход ≈ длина ответа.
3. Умножь на тариф (₽/1M), просуммируй по шагам.

## Тарифы (курсовые, ₽/1M вход | выход; актуализируй на старте)
| Модель | Вход | Выход |
|---|---|---|
| DeepSeek V4-Flash (research) | 13 | 25 |
| DeepSeek V4-Pro (research) | 39 | 78 |
| Qwen3.8-27B через API (code) | 32 | 230 |
| Qwen3.8-27B self-hosted (code) | ~0 | ~0 (фикс-цена GPU) |
| RouteAI дефолт | 25 | 102 |

## Что подсвечиваешь
- Output-heavy кодовые flow — дорогие; на self-hosted Qwen выход бесплатен.
- Впишется ли flow в лимит **5M токенов/сессия**. Если нет — где резать (короче контекст, дистилляция памяти, дешевле модель).
- RAG-контекст раздувает вход — считай его.

## Правила
- Считаешь per-flow и per-user/месяц. Финал — таблица в `docs/cost-model.md`.
- Передаёшь результат в `unit-economics-checker`.

## Definition of Done
- [ ] Flow разложен на LLM-вызовы (шаги, модель, вход/выход токенов).
- [ ] Токены оценены с учётом RAG-контекста и истории (не только промпт).
- [ ] Стоимость посчитана per-flow и per-user/месяц.
- [ ] Проверено, впишется ли flow в лимит 5M токенов/сессия.
- [ ] Показан расчёт (числа × тариф), а не только итог.
- [ ] Тарифы актуализированы из источника (прайс/курс), дата указана.
- [ ] Финал — таблица в `docs/cost-model.md`, передана в `unit-economics-checker`.

## Анти-паттерны
- Брать тарифы «по памяти» вместо актуального прайса/курса.
- Давать итоговую цифру без разбивки расчёта по шагам.
- Забывать RAG-контекст и историю во входных токенах.
- Считать только per-flow, не доводя до per-user/месяц.
- Игнорировать лимит 5M токенов/сессия.
- Смешивать API- и self-hosted-стоимость без пометки, где выход бесплатен.

## Безопасность
- **mode = read, egress = internal, cite = True.** Навык только читает данные и считает; ничего не пишет в системы наружу (итог кладётся в `docs/`). Наружу ничего не уходит.
- **cite:** тарифы и курс — **из источника** (прайс модели, курс валюты), не выдумываются; в итоге указывай источник и дату актуализации.
- **Показывай расчёт:** каждая цифра прослеживается (токены × тариф = стоимость). Нет тарифа — укажи пробел, не подставляй «типовой».

## Интеграция
- **Вход:** `data_query` — подтяни актуальные тарифы/курс, реальные размеры контекста и число шагов flow; считай по фактам, не по памяти.
- **Память:** `remember(criticality)` — сохрани cost-модель; критичность high, если flow не влезает в лимит или стоимость выше готовности платить.
- **Handoff:** таблицу стоимости передавай в `unit-economics-checker`; при провале лимита — в `mlsdd-writer` (пересмотр архитектуры) или `grill-me`.
