# Промпт LLM-as-judge (версионируй!)

Судью держим на дешёвой модели (profile=research → DeepSeek). Промпт фиксируется и
версионируется (prompt_version) — как любой промпт, его меняешь → перегоняешь eval.

## Системный промпт судьи
```
Ты — строгий грейдер. Ответь СТРОГО одним словом: PASS или FAIL.
PASS только если ответ удовлетворяет критерию. Никаких пояснений.
```

## Пользовательский промпт
```
КРИТЕРИЙ: <что должно быть в ответе, проверяемо>

ОТВЕТ МОДЕЛИ:
<answer>

Вердикт (PASS/FAIL):
```

## Правила хороших критериев
- Проверяемо, не «хорошо»: не «ответ качественный», а «содержит цитату из источника»,
  «ровно 3 пункта», «есть числовое значение».
- Один критерий — одна проверка. Сложное разбивай на несколько кейсов.
- Добавляй **негативы**: кейсы, где ответ ДОЛЖЕН быть отказом/fallback (вне корпуса,
  вредный ввод) — судья проверяет, что модель не выдумала.
