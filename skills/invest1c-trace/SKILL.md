# Трассировка цепочки от симптома (invest1c-trace)

Ты не перебираешь нарушения списком — ты ведёшь расследование. Симптом (незакрытый НДС, расхождение сальдо, «висящая» дебиторка) — это только видимая точка. Твоя работа: от симптома протянуть всю цепочку операции **реализация → взаиморасчёты → НДС** и показать, на каком именно звене рвётся связь и расходятся суммы. Звено с разрывом — корень; остальное — следствие.

## Когда применять
- Есть симптом на одном участке (НДС/расчёты/дебиторка) и надо понять причину по всей цепочке.
- Нужно связать реализацию с оплатой на расчётном счёте и со счётом-фактурой выданным.
- Перед заключением (`invest1c-verdict`) — чтобы вывод опирался на прослеженную цепочку, а не на одну запись.

## Метод (пошагово)
1. **Возьми граф** (`audit1c-graph-build`): документы, basis-ссылки (Основание_uuid), обратный индекс referenced_by.
2. **Запусти трассировку** инструментом `invest1c_trace`: для каждой реализации он находит дочерние документы — счёт-фактуру выданный и поступление на р/с — по реальным ссылкам.
3. **Сверь суммы по звеньям**: СуммаДокумента реализации ↔ сумма оплаты; выделен ли НДС (СуммаНДС) и предъявлен ли он счётом-фактурой.
4. **Определи звено-разрыв**: нет счёта-фактуры → НДС не предъявлен; нет оплаты → дебиторка; сумма оплаты ≠ сумме реализации → несходимость расчётов.
5. **Не выдумывай звенья**: если ссылки нет — это и есть находка, а не повод достроить цепочку догадкой.

## Definition of Done
- [ ] По каждому симптому построена цепочка реализация→оплата→НДС из реальных basis-ссылок.
- [ ] Для каждого звена указан статус (есть / РАЗРЫВ) и сумма.
- [ ] Проведена сверка сумм (реализация ↔ оплата, НДС выделен/предъявлен), зафиксирована разница.
- [ ] Названо звено-корень разрыва — от него дальше строится заключение.
- [ ] Ни одно звено не достроено догадкой — только подтверждённые ссылки.

## Анти-паттерны
- Не подменяй расследование пересказом одной записи — цепочка целиком.
- Не достраивай отсутствующее звено «по логике» — отсутствие ссылки само есть находка.
- Не сглаживай расхождение сумм — фиксируй разницу в рублях.
- Не смешивай разные цепочки в одну — каждая реализация ведётся отдельно.

## Безопасность
- **mode=read** — трассировка поверх графа; данные 1С не изменяются.
- **egress=internal** — внутри периметра.
- **cite=True** — каждое звено подтверждено конкретным документом и ссылкой.

## Интеграция
- **Вход**: граф из `audit1c-graph-build` (после `audit1c-extract`).
- **Результат**: список цепочек-расследований (звенья, сверка, звено-разрыв) — на доску.
- **Handoff**: → `invest1c-verdict` (заключение по каждой цепочке + норма НК гл.21 + HITL).
