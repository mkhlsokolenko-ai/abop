# DCF Valuation

Ты строишь оценку стоимости методом дисконтированных денежных потоков. Не «красивая цифра для питча», а обоснованная модель, где каждое допущение видно, а результат — **диапазон**, а не одна точка. Твоя задача — превратить прогноз денежных потоков в стоимость капитала (equity value) с прозрачной логикой и проверкой чувствительности.

## Когда применять
- Нужна фундаментальная оценка компании/проекта, не зависящая от рыночных мультипликаторов сравнимых.
- Есть или можно спрогнозировать свободный денежный поток на горизонт 5–10 лет.
- Оценка сделки M&A, входа инвестора, impairment-теста, обоснования цены.
- Как перекрёстная проверка к оценке по мультипликаторам (comps) и precedent transactions.

## Метод (пошагово)
1. **Выбери базу потока: FCFF или FCFE.**
   - **FCFF** (поток на всю фирму, до долга) = EBIT·(1−t) + D&A − Capex − ΔNWC. Дисконтируется по **WACC**, даёт **Enterprise Value**.
   - **FCFE** (поток на акционеров, после долга) = Чистая прибыль + D&A − Capex − ΔNWC + Чистые заимствования. Дисконтируется по **Re** (стоимость капитала), даёт напрямую **Equity Value**.
   - По умолчанию используй FCFF (устойчивее к изменению структуры капитала); FCFE — для банков/финкомпаний, где долг — часть операционки.
2. **Спрогнозируй FCF по драйверам, а не «плюс 10% в год».**
   - Выручка: объём × цена, или сегменты × темп; привяжи к драйверу (клиенты, ARPU, доля рынка).
   - Маржа: EBIT-маржа как траектория к устойчивому уровню, не константа с потолка.
   - Capex: как % выручки или по инвест-плану; в терминальном году Capex ≈ D&A (стабильное состояние).
   - ΔNWC: через дни оборачиваемости (DSO/DIO/DPO) или % от прироста выручки.
3. **Посчитай WACC.**
   - **Re через CAPM**: Re = Rf + β·ERP (Rf — безрисковая ставка суверенного долга в валюте потока; β — левериджированная бета сектора; ERP — премия за риск рынка). Для развивающихся рынков добавь Country Risk Premium.
   - **Rd** — стоимость долга после налога: Rd·(1−t) по фактической/рыночной ставке заимствования.
   - **WACC** = We·Re + Wd·Rd·(1−t), веса We/Wd — по **рыночной** (целевой) структуре капитала, не балансовой.
4. **Терминальная стоимость — двумя методами, обязательно сверить.**
   - **Gordon Growth**: TV = FCF_(n+1) / (WACC − g), где **g < WACC** и g ≤ долгосрочный номинальный рост экономики (обычно ≤ инфляция + реальный ВВП). g выше WACC = бесконечная стоимость, ошибка.
   - **Exit Multiple**: TV = метрика терминального года (EV/EBITDA или EV/EBIT) × мультипликатор сравнимых.
   - Сверь: имплицитный g из exit-multiple и имплицитный мультипликатор из Gordon должны быть правдоподобны. Расхождение >20% — разберись, не усредняй молча.
5. **Дисконтируй.**
   - PV = Σ FCF_t / (1+WACC)^t + PV(TV). TV дисконтируется на тот же год n.
   - Опционально **mid-year convention**: степень (t−0.5) — потоки поступают в среднем в середине года; повышает PV, уместно для равномерного бизнеса.
6. **Мост EV → Equity Value.**
   - Equity = EV − Чистый долг (долг − денежные средства и эквиваленты) − Миноритарии (NCI) − Привилегированные акции − Пенсионный дефицит + Ассоциированные/инвестиции. На акцию: Equity / разводнённое число акций.
7. **Sensitivity-таблица WACC × g.**
   - Двумерная матрица: WACC по строкам (±1–1.5 п.п.), g по столбцам (±0.5–1 п.п.). Покажи, как стоимость «дышит» — DCF крайне чувствителен к терминалу.

## Definition of Done
- [ ] Все ключевые допущения выписаны явно (Rf, β, ERP, WACC, g, маржа, Capex/выручка, горизонт).
- [ ] Терминальная стоимость посчитана **двумя методами** (Gordon + exit-multiple) и сверена.
- [ ] Проверено неравенство **g < WACC** и g ≤ долгосрочного роста экономики.
- [ ] Построена **sensitivity-таблица WACC × g**.
- [ ] Мост EV→Equity полный (чистый долг, миноритарии, преф).
- [ ] Результат — **диапазон стоимости** (напр., по краям таблицы чувствительности), а не одно число.
- [ ] Каждое число прослеживается до источника из Data Plane.

## Анти-паттерны
- Не задавай g ≥ WACC и не бери g выше долгосрочного роста экономики — это математически ломает терминал.
- Не бери одну терминальную стоимость без перекрёстной проверки вторым методом.
- Не считай WACC по **балансовым** весам капитала — только рыночные/целевые.
- Не выдавай единственную точку — DCF без диапазона вводит в заблуждение.
- Не рисуй «хоккейную клюшку» маржи без драйвера, обосновывающего рост.
- Не забудь вычесть чистый долг и миноритариев при переходе EV→equity.
- Не смешивай валюту потока и безрисковой ставки (поток в ₽ → Rf в ₽).
- Не выдумывай числа: нет данных по β/ERP/долгу — скажи прямо, где пробел, и не подставляй «типовое».

## Безопасность
- **mode=read** — навык только читает данные, ничего не пишет в системы.
- **egress=internal** — данные и результат остаются внутри периметра; наружу ничего не уходит.
- **cite=True** — каждое число (выручка, долг, ставки, беты) сопровождается ссылкой на источник в Data Plane. Числа **не выдумываются**. Если данных для допущения нет — прямо укажи пробел и не подставляй значение «по умолчанию».

## Интеграция
- **Вход**: получай факты (историческая выручка, EBIT, D&A, capex, долг, денежные средства, число акций, рыночные ставки) через `data_query` — только машиночитаемые данные Data Plane, без ручного ввода «на глаз».
- **Результат**: сохраняй оценку и допущения через `remember(criticality)` — оценка стоимости обычно **высокой критичности** (влияет на цену сделки/решение об инвестициях).
- **Handoff**: при необходимости построить питающую модель — передай задачу семье `three-statement-model` (источник FCF); готовую оценку — роли, отвечающей за инвестиционное решение или подготовку сделки.
