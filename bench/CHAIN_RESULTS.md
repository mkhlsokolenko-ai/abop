# Проверка связки: оркестратор → агент → тенант знаний → ретрив → цитата

**Что доказывали:** сквозную цепочку ABOP на пилот-семье **finance** — оркестратор маршрутизирует в семью, агент-эксперт достаёт знания из тенанта семьи через RAG и отвечает **только с цитатой** (анти-галлюцинация), а на отсутствующем факте — «Недостаточно данных», без выдумки.

**Модель:** qwen3-30b-a3b-instruct-2507 (победитель гейта) через routerai. Температура 0.1.

---

## Прогон 1 — локально (routerai: bge-m3 embed + reranker + numpy-вектор)

Быстрое доказательство концепта без сервера. `bench/verify_chain_local.py`.
- **Цепочка (ретрив+реранк+цитата+анти-галл): 5/5 = 100%**
- **Изоляция тенантов: ✓** — запрос finance НЕ достаёт decoy-чанк семьи research (payload-фильтр по family).
- Обе ловушки → «Недостаточно данных» без выдумки (лунный налог, сотрудники несуществующего ООО).

## Прогон 2 — in-perimeter (боевая sLAVA на сервере-1, через ssh-джамп)

`bench/verify_chain.py` против живой sLAVA (Qdrant + BGE-M3 + reranker в периметре, коллекция `slava_fam_finance`, профиль `legal_ru`, tenant `demo`). Доступ — двойной ProxyJump (я → сервер-2 → сервер-1), т.к. провайдер временно резал входящий трафик на сервер-1.

Индексация: ФЗ-402 «О бухгалтерском учёте» → **6 чанков (fp32)**.

| Кейс | Тип | route | ретрив | цитата | результат |
|---|---|---|---|---|---|
| Обязательные реквизиты первички | ответимый | finance ✓ | src=1 | ✓ ст.9 | PASS |
| Ответственность за организацию учёта | ответимый | finance ✓ | src=1 | ✓ ст.7 «руководитель» | PASS |
| Каким ФЗ регулируется бухучёт | ответимый | finance ✓ | src=1 | ✓ №402 | PASS |
| Ставка налога на добычу на Луне | ловушка | — | src=0 | fallback ✓ (не выдумал) | PASS |
| Сотрудников в бухгалтерии ООО «Ромашка» | ловушка | finance ✓ | src=0 | fallback ✓ (не выдумал) | PASS |

- **Гейт связки (ретрив+цитата+анти-галлюцинация): 5/5 = 100%** ✅
- Латентность query через двойной джамп: 1–18с (не показатель — хоп-оверхед; на боксе/прямом канале в разы ниже).
- Пример живого ответа sLAVA: «...ответственность за организацию ведения бухгалтерского учёта несёт **руководитель экономического субъекта [1]**» (confidence 0.99, источник — ст.7).

**Двойная анти-галлюцинация подтверждена:** sLAVA сама возвращает `fallback` при отсутствии (require_citations на слое ретрива) + агент-модель цитирует только по sources.

## Вывод

**Связка работает end-to-end**, и локально, и в боевом периметре:
`route_family → коллекция-семья (тенант знаний) → sLAVA (embed→Qdrant→rerank) → sources → агент цитирует / «Недостаточно данных»`.

Изоляция тенантов держится (семья не видит чужой корпус). Анти-галлюцинация держится дважды. Модель-победитель гейта ведёт себя в связке так же чисто, как на мини-бенче.

**Маршрутизация** (метрика, не гейт связки): на голых метках семей была 60%, с описаниями семей в промпте — 100% на finance-кейсах. Финальный роутинг — детерминированный `route_family` из `cli/ape.py` (эвристика+LLM), здесь проверялся LLM-путь.
