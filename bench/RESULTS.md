# Результаты мини-бенча — выбор MoE-движка под 32ГБ (routerai.ru)

**Прогон:** 6 кандидатов × 20 RU-кейсов, T=0.1, endpoint `routerai.ru/api/v1` (пре-бокс, аренду не палим).
**Гейт:** все 5 измерений ≥ порога И `cite` (анти-галлюцинация) чист (HARD). Пороги: cite≥90, json_tool≥90, route≥75, dod≥70, ru≥70.
**Датасет:** после починки 3 хрупких кейсов (неоднозначный `route-research` → чистый research; 2 `ru` `contains`→`contains_any` с синонимами).

## Вердикт

**Основной движок волн — `qwen3-30b-a3b-instruct-2507`.** 100% по всем 5 измерениям, самый терсый выхлоп (833 ток/20 кейсов) и быстрый (p95 7.5с). Совпадает с якорем `ABOP_RUNTIME_ARCHITECTURE.md §7-ter`.

**Проверенный резерв — `openai/gpt-oss-20b`.** Тоже 100% начисто, латентность как у лидера, Apache-2.0, легче по VRAM (~13ГБ MXFP4).

**Оба лезут в 32ГБ Int4/MXFP4** (30b-a3b ~17ГБ, gpt-oss-20b ~13ГБ) с рабочим KV-окном.

## Отклонённые и почему

- **qwen3.5-35b-a3b** — «думающая»: ru между прогонами 100→66.7 (**вариативность даже при T=0.1**), p95 25с, выхлоп 15–30к токенов. Непредсказуемость + стоимость несовместимы с проводным governance-рантаймом. Если нужен thinking-судья — тестировать отдельно `qwen3-30b-a3b-thinking-2507`.
- **qwen3.6-35b-a3b** — отдаётся в многословном режиме, ломает строгий JSON (dod 0%, «не JSON»). Непригодна для ReAct как есть.
- **nemotron-3-nano-30b-a3b** — протечка ловушки в cite (выдумка вместо «Недостаточно данных») + слабый роутинг.
- **qwen3-coder-30b-a3b** — json_tool 75 + route 50; кодер не для governance-оркестрации.

## Наблюдения для бокса

- Строгий JSON (`json_tool`) держат почти все — узкое место не формат, а **анти-галлюцинация** (водораздел: 3 из 6 протекли на ловушках) и **устойчивость формата** (thinking-модели ломают dod).
- Латентность/выхлоп кандидатов-победителей низкие → высокий concurrency на 32ГБ реалистичен.
- Числа латентности здесь — через агрегатор routerai; на боксе перегнать бенч (`--base-url http://BOX:8000/v1`) для реальных значений под vLLM + APC.

## Следующий шаг

Арендовать 32ГБ бокс → vLLM с `qwen3-30b-a3b-instruct-2507` (Int4, Automatic Prefix Caching) → перегон бенча на боксе → `_mcp_call`→локальный `infer()` → фронт-прототип на живой endpoint (оживить Канву/Пульт). Резерв `gpt-oss-20b` — если понадобится Apache-лицензия/меньше VRAM.
