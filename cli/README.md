# ape — CLI курса AI Product Engineer

Единая точка доступа к моделям курса. Один вход через GitHub, одна квота, роутинг
задач на нужную модель: **код → Qwen3.8-27B (RouteAI)**, **ресёрч → DeepSeek**.
Зависимостей нет — только стандартный Python 3.9+.

## Установка

**Вариант A — pip из репозитория (рекомендуется, нужен git):**
```bash
pip install "git+https://github.com/mkhlsokolenko-ai/ai-product-engineer#subdirectory=cli"
```

**Вариант B — один файл, без git и без установки:**
```bash
curl -O https://s3.engineer-ai.pro/materials/ape.py
python ape.py login      # дальше вместо "ape" пиши "python ape.py"
```

## Быстрый старт (2 команды)
```bash
ape login                       # откроется браузер → вход через GitHub
ape code "напиши FastAPI-эндпоинт /health с тестом на pytest"
```

## Команды

| Команда | Что делает | Модель |
|---|---|---|
| `ape login` | вход через GitHub, токен сохраняется и **авто-обновляется** | — |
| `ape code "<задача>"` | сгенерировать/поправить код | **Qwen3.8-27B** (RouteAI) |
| `ape ask "<вопрос>"` | ресёрч, объяснения, сравнение подходов | **DeepSeek** |
| `ape chat "<запрос>"` | общий профиль | каскад |
| `ape rag index <файлы>` | загрузить документы в свою RAG-коллекцию | — |
| `ape rag search "<q>"` | поиск по своей коллекции | — |
| `ape usage` | расход токенов и квота недели | — |
| `ape whoami` / `ape logout` | кто я / выйти | — |
| `ape session new` | новая рабочая сессия (техническая группировка вызовов) | — |

## В чём разница `code` и `ask`
- **`ape code`** идёт на Qwen3.8-27B через RouteAI: быстро, «мышление вслух» отключено —
  на выходе чистый код. (Опция: вернуть на свою RTX 6000 через `ROUTEAI_CODE_CASCADE=local/...`.)
- **`ape ask`** идёт на DeepSeek: сильнее в рассуждениях, ресёрче, разборе вариантов.
- Правило курса: **пишешь код — `code`, думаешь/исследуешь — `ask`.**

## Полезное
```bash
ape code "добавь обработку ошибок" -f app.py      # приложить файл
git diff | ape code "напиши сообщение коммита" --stdin
ape code "разбери этот стек-трейс" -f err.log
ape usage                                         # сколько осталось за неделю
```

## Флаги
`-f/--file <path>` (можно несколько) · `-s/--system "<промпт>"` · `--stdin` · `--max-tokens N`

## Квоты
Один лимит — **25M токенов в неделю** на студента (сброс в понедельник). Лимитов на число
сессий/подключений нет. `ape usage` показывает остаток.

## Конфиг
Токены и id сессии — в `~/.ape/config.json` (права 600). `ape logout` удаляет.
